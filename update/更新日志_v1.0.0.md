## 📝 更新日志

- 更新版本号为v1.0.0

---

#### 新功能

**内置播放器正式上线**

- **视频播放入口** – 设置页直接提供「视频播放」，可打开媒体库、本地视频、网页播放和 WebDAV 番剧库。首次使用时可查看各来源的操作引导。
- **番剧详情选集与续播** – 在「设置 → 功能」开启详情页播放按钮后，可从详情选择本地、WebDAV、网页或外部应用。已关联的剧集可直接选集，或接着上次的进度继续。外部播放仍可选择 Animeko、哔哩哔哩或每次询问。
- **统一媒体库** – 按本地、网页和 WebDAV 筛选作品，集中浏览各季与集数。支持将网页番剧加入媒体库，从「继续观看」打开最近播放的剧集。

**本地文件与 WebDAV**

- **本地视频扫描** – 授权文件夹后，在后台识别番名、季数和集数，结合 NFO、bangumi.ini 与 Bangumi / TMDB 资料归档。支持增量重扫，只补充变化的文件。即使还没有追番记录，也能在媒体库中选集播放。
- **整理和确认关联** – 可整组确认、重新识别或解除匹配，也能单独纠正文件关联。支持隐藏和恢复显示本地视频。缺失文件保留原有记录，恢复目录访问后可以再次扫描。
- **WebDAV 番剧库** – 可测试连接、设置媒体根目录并扫描远程视频，也可按服务器原来的目录打开文件。记住最近浏览的目录和滚动位置，支持续播和同目录匹配连播。播放服务器配置独立于数据备份，播放密码存入加密存储。

**网页播放**

- **视频直链与网页解析** – 支持 MP4、HLS 和 DASH 等媒体来源。兼容站点可解析出剧集和线路，提供选集、切换线路和播放失败后的重试入口。
- **按番名找剧集** – 可用内置规则搜索，也可导入、管理兼容的 Kazumi HTML / API 规则。最近输入的地址与网页剧集进度分别保存，重新播放时会按需获取新的媒体地址。

**播放交互与进度**

- **竖屏、全屏和画中画** – 竖屏可直接选集，进入全屏后可按视频宽高比选择方向。支持快进快退、亮度和音量手势、长按加速、画面比例调整，以及画中画。全屏播放时保持屏幕常亮。
- **清晰度、音轨和字幕** – 按来源显示实际可用的清晰度与轨道。媒体库和 WebDAV 支持匹配同目录字幕，也可手动载入本地外挂字幕。字幕加载失败时，视频可继续播放。
- **播放器偏好** – 可设置默认倍速和画面比例，控制长按倍速、硬件解码、记忆播放位置及自动播放下一集。
- **联动追番进度** – 可开启「看完后更新追番进度」。已确认关联且集数明确的正片会按有效观看时长记录完成，连续看完的集数才推进追番进度。跳过的集数不会被标记为已看。

**自定义收藏夹**

- **分组和排序** – 在「收藏」页创建、命名和搜索添加作品，可更换收藏夹封面，拖动调整收藏夹及夹内番剧的顺序。单部作品可加入多个收藏夹。
- **打开与收起** – 点开收藏夹后，可用双指向内捏合回到收藏页。移出收藏夹或删除收藏夹时，作品仍保留在「全部收藏」。取消收藏时，会先提示受影响的收藏夹。
- **随备份迁移** – WebDAV 的 JSON 和完整 ZIP 备份均可保存和恢复收藏夹、夹内番剧及自定义封面。

**批量添加番剧**

- **跨关键词和来源多选** – 在主页的「添加番剧」中开启批量模式，切换关键词或 Bangumi / TMDB 来源时保留已选作品。一次保存，自动跳过已存在的条目并显示数量。未开播作品归入「想看」，其余归入「在看」。

#### 体验优化

- **多季作品堆叠** – 优先按 Bangumi 前传、续集关系识别，再用标题季号和明确的主标题补齐。缺少中间一季时仍可识别关系明确的系列，同时区分同名作品、不同世界观和外传。补齐资料或重新匹配后会重新识别归组。
- **主页搜索与收藏** – 同一个按钮按当前状态清空关键词或退出搜索。长按搜索结果时保留列表和搜索条件。导航栏中的收藏图标选中后以实心显示，多季堆叠的背卡在入场时完整绘制。
- **设置搜索与表单** – 根据屏幕大小、深色模式及相关开关显示可用设置，补齐导航样式、添加按钮、状态栏和今日放送的定位。添加番剧、账号、反馈及 Markdown 导入等页面使用统一的输入框样式。
- **全屏过渡与播放恢复** – 统一详情页、媒体库和播放器的进入及返回动画。从后台返回时可接续仍在运行的播放会话。WebDAV 加强续播和进度定位校验，并在资源读取失败时显示可操作的提示。
- **更新包缓存** – 启动时清理已安装版本及更早版本的 APK 缓存，并保留待安装的较新版本。

#### 性能与工程

- **媒体扫描与浏览** – 用后台分批扫描、按需补全资料和分页列表降低大目录的处理量。WebDAV 目录与字幕读取设有大小和时间限制，媒体播放、网页请求与 WebDAV 凭据按来源处理。
- **兼容与构建** – 升级 Kotlin、Gradle、Android Gradle Plugin、Compose、Room 和 Media3。编译 SDK 更新至 37.1，最低安装版本仍为 Android 8.0。增加媒体库、收藏夹的数据库迁移与回归测试。
