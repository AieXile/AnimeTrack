我们非常重视你的隐私。本政策说明 AnimeTrack 收集哪些数据、如何使用与保护这些数据。使用本应用即表示你同意本政策的全部内容。

# 一、我们收集的信息

**本地数据（默认不离开你的设备）**

- 追番记录、观看进度、评分与备注
- 外观、功能等偏好设置
- 本地日志（仅记录应用行为与异常信息，保留 3 天，不含敏感个人数据）

以上数据存储在本机，除非你主动开启同步或导出，不会上传。

**账号数据（仅注册登录后）**

- 用户名、邮箱地址（用于登录、验证码与找回密码）
- 密码（服务端加密存储，我们无法查看明文）
- 设备信息（设备标识、名称、平台），用于多端登录管理与账号安全

**云端数据（仅登录并同步后）**

- 云端追番记录，用于多设备间同步
- 意见反馈记录（反馈内容与回复）

# 二、数据的使用

- 提供追番记录的云端同步与多设备登录
- 在你提交反馈时用于处理问题与回复
- 本地日志会在你主动提交反馈时作为附件上传，用于排查问题

# 三、第三方服务

本应用会与以下第三方服务通信，各自受其隐私政策约束：

- **Bangumi / TMDB**：查询番剧元数据与评分
- **Bilibili**：在你主动登录后同步追番列表
- **GitHub**：检查应用更新
- **一言（Hitokoto）**：获取随机语录
- **WebDAV**：由你自行配置的同步服务器，数据不经过我们

# 四、权限使用

- **通知权限**：仅用于番剧更新提醒，可选择关闭

# 五、数据的存储与安全

- 账号数据通过 HTTPS 传输，密码加密存储
- 本地日志保留 3 天后自动清理
- 我们不会出售或向无关第三方提供你的个人数据

# 六、数据的删除

- 退出登录后，云端追番记录仍会保留，可随时重新登录恢复
- 注销账号：提交后有 7 天冷静期，期间重新登录可撤销；到期后账号信息、云端追番记录、反馈记录等将被永久删除

# 七、政策更新

我们可能不定期修订本政策，修订后会在应用内提示。继续使用即视为接受修订后的政策。
